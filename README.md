# Prueba Tecnica NTT DATA

## Tecnologias usadas y experiencia
- PHP 8.3: uso de tipado, clases de dominio, DTO y manejo de arreglos asociativos.
- Laravel 13: enrutamiento, controladores, inyeccion de dependencias, cliente HTTP y respuesta JSON.
- Spatie laravel-route-attributes: definicion de rutas mediante atributos en el controlador.
- HTML + CSS + JS: consumo del endpoint backend y render del listado.

Experiencia aplicada en este reto:
- Modelado simple orientado a dominio (Client como objeto).
- Separacion por capas (Interfaces, Application, Infrastructure, Domain).
- Integracion con API externa y transformacion de contrato de datos.
